# Document Q&A Assistant — RAG

A production-oriented Document Question Answering Assistant built using
Retrieval-Augmented Generation (RAG).

## Project Goal

The goal of this project is to build and understand an end-to-end RAG
system that can answer questions from user-provided documents while
minimizing hallucinations through retrieval, relevance checks, citations,
and fallback mechanisms.

## Planned Capabilities

- Document ingestion
- PDF, DOCX, TXT and Markdown support
- OCR fallback for scanned documents
- Document chunking
- Embedding generation
- Vector search
- Hybrid retrieval
- Reranking
- Grounded answer generation
- Source citations
- Retrieval and generation fallbacks
- RAG evaluation
- REST API
- Web interface
- Automated testing
- Docker deployment
